# prototype

どれも Chrome でダブルクリックして開くだけで動きます（サーバー・ターミナル・インストール不要）。

| ファイル | 内容 |
|---|---|
| `slide-sensei.html` | **スライド先生 本体**。画面共有した PowerPoint を見て、次の一手を光らせて案内する |
| `practice-slide.html` | PowerPoint 風の練習用画面。PowerPoint がない PC でのデモ用（タブ共有で使う） |
| `capture-test.html` | 画面収録と変化検知の計測ツール。閾値やカーソル除外の調整に使う |
| `index.html` / `app.js` / `styles.css` | 初期の Photoshop 版「操作ナビ」の UI モック（参考） |
