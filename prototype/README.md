# 操作ナビ UI試作

`index.html`をダブルクリックすると、ブラウザでそのまま動作します。
サーバー、ターミナル、追加インストールは不要です。

## 試せる操作

1. 「開始する」で色調補正の案内を開始
2. Photoshop風画面の調整レイヤーボタンを操作
3. トーンカーブ、明るさ、色温度、自然な彩度を手動調整
4. 「案内」と「自動実行」を切り替え
5. 自動実行前の対象、操作、結果を確認
6. 「戻る」「次へ」「判断できない」「停止」
7. 設定タブと各種トグル

この試作は画面と操作感を確認するためのHTML版です。
実際の画面収録、ローカルAI、Photoshop自動操作はネイティブ版で実装します。
