## 0. はじめる前に（1回だけ）

- [ ] Chrome の「画面収録」を許可（システム設定 → プライバシーとセキュリティ → 画面収録とシステムオーディオ録音）→ Chrome を再起動
- [ ] AI の設定で Gemini API キーを入れる（社外秘・個人情報が写る画面では使わない。無料枠は製品改善に使われる）
- [ ] 拡張機能 `extension/` を `chrome://extensions` で読み込む（デベロッパー モード ON）
- [ ] 画面の設定を書き留める: Mac の機種・画面の大きさ・Retina か・ダーク／ライト・ソフトの版

## 1. 測ること（1つの課題ごと）

| 項目 | 測り方 |

## 4. 結果の読み方

- **光った場所が 7 割未満**のソフト → 画面の読み方（文字認識・番号札）を、そのソフト向けに直す
- **間違って進んだ**が出た → 「できた」判定がゆるすぎる。その手順の前後の画面を `tools/capture-test.html` で保存して、自動テストに足す
- **手で「できた ✓」が多い** → 判定がきびしすぎる
- Blender・Illustrator で文字がほとんど読めない → 画面共有だけでは限界。そのソフトのアドイン（Blender は Python アドイン、
  Illustrator は UXP プラグイン）で、Office と同じように**ソフトの中から状態を読む**方式を検討する
