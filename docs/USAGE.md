# そうさ先生 使い方ガイド

そうさ先生には、教わりたいソフトに合わせて **3つの使い方** があります。

| 教わりたいソフト | 使い方 | 光る場所 | 準備 |
|---|---|---|---|
| どのソフトでも（PowerPoint・Photoshop・Blender など） | **① 本体（画面共有）** | ミニ窓とプレビューの中 | Chrome だけ |
| Web アプリ（Google Colab など） | **② Web アプリ連携（サイドパネル）** | **ページの上に直接** | Chrome 拡張機能を入れる |
| Excel・Word・PowerPoint | **③ Office アドイン** | 文書の中を選択／リボンは道順で表示 | https で公開してから入れる |

迷ったら ① から。どの使い方でも「🧭 やりたいこと」を書けば AI が1手ずつ案内します（AI の設定が必要）。

---

## ① 本体（画面共有モード）

### 最初の1回だけ

1. **Google Chrome** で `index.html` をダブルクリックして開く
2. macOS の **システム設定 → プライバシーとセキュリティ → 画面収録とシステムオーディオ録音** で **Google Chrome を ON**
   → Chrome を一度終了して開き直す
3. AI を使うなら「⚙ 設定」→「🤖 AI」で設定する（下の「AI の設定」）

### 毎回の流れ

1. 教わりたいソフトを開いておく（PowerPoint がなければ「🧪 練習用画面を開く」）
2. **「▶ はじめる」** → 共有するものを選ぶ画面で **「画面全体」** を選んで「共有」
   - 画面全体だと、メニューやダイアログ（表のマス目、グラフの種類など）も見えるので反応が良くなります
   - ミニ窓（常に最前面の小さな案内の窓）が一緒に開きます。開かなければ点滅している「📌 ミニ窓で表示」を押す
3. 教わりたいソフトをクリックして前に出す。ミニ窓は画面の端へ動かしておく（位置は Chrome が覚えます）
4. 案内に従って操作する

### 2種類の案内

**決まったレッスン**（AI なしでも動く）
- 上の「レッスン」から選ぶ: はじめてのスライド／図形を使いこなす／見やすいデザインテーマ（PowerPoint 用）
- 文字で確かめられる手順は、できたら自動で次へ（カードが緑に光る）。それ以外は「できましたか？」と聞くので「できた ✓」

**🧭 AIにおまかせ**（どのソフトでも。AI が必要）
- ミニ窓の「🧭 やりたいことを書く」欄に、例えば「スライドに表を入れたい」「Photoshop で明るさを上げたい」と書いて「開始」
- AI が画面を見て次の一手を1つ出し、押す場所を光らせて読み上げます
- 操作して画面が変わると、AI が前後の画面を比べて「できたか」を確かめ、次の一手へ
- AI が「まだ」と言っても、できていれば「できた ✓」で進めます

### ミニ窓（案内パネル）のボタン

| ボタン | はたらき |
|---|---|
| できた ✓ ／ まだ | 「できましたか？」への返事 |
| ← 戻る | 1つ前の手順へ（決まったレッスンのみ） |
| やり直し | レッスン（おまかせ）を最初から |
| 🤖 AIに聞く | 今の画面を AI に見せて、次にやることを聞く |
| 次へ → | 今の手順を飛ばして次へ |

プレビューの下: 「⏸ 一時停止」（見守りを止める）・「共有を停止」

### ⚙ 設定

| 項目 | はたらき |
|---|---|
| 🤖 AI | AI の設定（下） |
| 🔤 文字認識 | 画面の文字を読んで、光らせる場所を探し、できたかを確かめる（普通は ON） |
| ⏩ 自動で次へ | ON にすると「できた？」のあと4秒で自動的に進む（操作中は待つ）。初期値は OFF |
| 🔊 音声 | 次の手順や「できましたか？」を読み上げる |
| 🌙 テーマ | 明るい／暗い表示の切り替え |

### AI の設定（「⚙ 設定」→「🤖 AI」）

| 方式 | 特徴 | 準備 |
|---|---|---|
| Chrome 内蔵AI（おすすめ） | 無料。画面の画像が**端末の外に出ない** | Chrome 148 以降。表示に「使えます」と出れば選ぶ。初回は「準備する」で約3〜4GBを取り込む |
| Gemini API 無料枠 | 無料（回数制限あり）。内蔵AIより賢い。**送った画像は Google の製品改善に使われる** | [Google AI Studio](https://aistudio.google.com/apikey) で APIキーを作って貼る。モデルは候補から選ぶ（`gemini-3.8-flash` がおすすめ） |

「接続テスト」で「✓ つながりました」と出れば準備完了。社外秘や個人情報が写る画面で Gemini を使わないでください。

## ② Web アプリ連携（Google Colab など）

Chrome 拡張機能を使います。**Colab のページの横（Chrome のサイドパネル）に案内が出て、Colab のページの上に直接**光ります。
本体（`index.html`）も画面共有もいりません。ボタン（アイコンだけのボタンも）の名前と位置をページから直接読むので、文字認識より正確です。

### 最初の1回だけ: 拡張機能を入れる

1. Chrome のアドレスバーに `chrome://extensions` と入力して開く
2. 右上の **「デベロッパー モード」** を ON
3. **「パッケージ化されていない拡張機能を読み込む」** → このアプリのフォルダの中の **`extension`** フォルダを選ぶ
   （前に入れたことがある場合は、「そうさ先生 Web 連携」の **🔄（再読み込み）** を押す）
4. ツールバーのパズルのアイコン（🧩）→「そうさ先生 Web 連携」の **📌** を押して、ツールバーに出しておく
5. Colab を開いて、拡張機能のアイコンを押す → 右側にサイドパネルが開く
6. サイドパネルの一番下 **「AI の設定・読み上げ」** で AI を選んで「保存」（本体とは別に、ここで1回設定が必要）

### 毎回の流れ

1. Google Colab のノートブックを開く
2. ツールバーの **そうさ先生のアイコン** を押す → 右側にサイドパネルが開く
3. やりたいこと（例:「セルを実行したい」「GPU を使いたい」）を書いて **「開始」**
4. Colab のページで、**赤く光っている場所**を操作する。ページが落ち着くと AI が確かめて次の一手を出します
   コードや文章を入力する手順では、AI が書いた中身が **「✍ 入力する内容」** に出ます。「📋 コピー」→ 光っている場所をクリック → 貼り付け（⌘V / Ctrl+V）
5. AI が「まだ」と判断したときや迷ったときは **「できた？」** が出ます。できていれば **「できた ✓」**
6. 困ったら **「🤖 AIに聞く」**（いまのページを見て聞き直す）、急ぐなら **「次へ →」**

### 学ぶための機能（サイドパネル）

- **💡 ポイント**: 手順ごとに「その操作で何を学べるか・なぜそうするのか」を短く説明します。コードを実行したあとは、結果やエラーの読み方も説明します
- **🎓 学習モード**（「設定」で ON/OFF。最初は ON）: コードを書く手順では、まず **ヒント** だけを出します。考えてから **「👀 答えを見る」**
- **🔍 1行ずつ説明**: 入力するコードを、1行ずつ何をしているか説明します
- **❓ 質問**: いつでも「sorted って何？」のように質問できます。AI がいまのページを見ながら答えます
- **📚 学んだこと**: 完了すると、手順ごとのポイントとまとめを一覧にします
- コードは長いものを一度に出さず、数行ずつ書いて実行し、結果を確かめながら進めます

### 注意

- サイドパネルは、**いま前に出ているタブ**を案内します。別のタブに切り替えると、そのタブの案内に切り替わります
- `chrome://` のページや Chrome ウェブストアでは案内できません（Chrome の決まり）
- ネット不要の練習ページ `practice-colab.html`（ダブルクリックで開くファイル）で試すときだけ、
  「そうさ先生 Web 連携」の **「詳細」→「ファイルの URL へのアクセスを許可する」** を ON にしてください。本物の Colab では不要です
- 学校や会社の Chrome で拡張機能を入れられない場合は、① の画面共有で使ってください

### 本体とつなぐ使い方（従来どおり）

`index.html` の **「🌐 Web アプリにつなぐ」** からつなぐこともできます（ミニ窓で案内し、レッスンも使える）。
この場合は「ファイルの URL へのアクセスを許可する」を ON にして、`index.html` を再読み込みしてから使います。
安全のため、拡張機能はそうさ先生の本体のページ（ダブルクリックで開いた `index.html`）とだけやりとりします。
GitHub Pages などで公開した本体から使うときは、`extension/manifest.json` の `content_scripts` の `matches` に、その URL（例: `https://ユーザー名.github.io/リポジトリ名/*`）を足してください。

## ③ Office アドイン（Excel・Word・PowerPoint）

Office の右側の「作業ウィンドウ」に案内を出します。Office から文書の状態を正確に読むので、「できたか」の判定が確実です。

### 入れる前に: https での公開が必要

Office アドインは https で公開した場所からしか読み込めません。GitHub Pages などで公開してから入れます（まだ公開していなければ、先に公開が必要です）。

### 最初の1回だけ: 入れ方

1. ターミナルで、公開した URL を書き込んだマニフェストを作る:
   ```bash
   tools/set-office-url.sh https://ユーザー名.github.io/リポジトリ名
   ```
   → `dist/manifest.xml` ができる
2. Finder で **⌘⇧G** を押し、次のフォルダを開いて `manifest.xml` をコピー（フォルダがなければ作る）
   - Excel: `~/Library/Containers/com.microsoft.Excel/Data/Documents/wef`
   - Word: `~/Library/Containers/com.microsoft.Word/Data/Documents/wef`
   - PowerPoint: `~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef`
3. Office を開き直す
4. 作業ウィンドウの一番下「AI の設定・読み上げ」で「Gemini API 無料枠を使う」にチェック、APIキーを貼って「保存」
   （Office の中では Chrome 内蔵AI は使えません。本体とは別に、ここでも設定が必要です）

### 毎回の流れ

1. 「ホーム」→「アドイン」から「そうさ先生」を開く
2. 上の欄にやりたいこと（例:「A1〜C5 に罫線を引きたい」「見出しを太字にしたい」「2枚目に図形を入れたい」）を書いて「開始」
3. 作業ウィンドウに次の一手が出ます
   - **赤いチップ**（ホーム › 罫線 › 格子）が、リボンで押す場所の道順
   - **文書の中の場所**（A1:C5 など）は自動で選択されます。「見せる」でもう一度選択
4. 操作すると、AI が前後の文書を比べて確かめ、次の一手へ。最後に「🎉 できました！」

ボタン: 「🤖 AIに聞く」（今の状態で聞き直す）・「やり直し」・「次へ →」（飛ばす）・「できた ✓／まだ」

### できないこと

- リボンのボタンそのものは光らせられません（Office の決まり）。光らせたいときは ① の画面共有と組み合わせます

## 練習用ページと道具

| ファイル | 使いどころ |
|---|---|
| `practice.html` | PowerPoint 風の練習用画面。PowerPoint がない PC でのデモや練習に（① で「タブ」を共有） |
| `practice-colab.html` | Colab 風の練習用ページ（ネット不要）。② の練習に |
| `practice-dark.html` | 暗い色のデザインアプリ風の練習用画面。アイコンだけのツールバーを、① の画面共有で試す |
| `tools/capture-test.html` | 画面収録と変化検知の計測ツール。反応が鈍い・反応しすぎるときの調査に |
| `index.html?test` | 本体の自動テスト（17件）。アドレスバーの末尾に `?test` を足して Enter |
| `tools/bundle-sidepanel.sh` | 拡張機能のサイドパネルの自動テスト（12件）を `dist/sidepanel-test.html` にまとめる。できたファイルを開くとテストが走る |
| `tools/bundle-agent.sh` | ページの読み取り係（ハイライトの位置・コードの入力欄など）の自動テスト（7件）を `dist/agent-test.html` にまとめる |
| `tools/bundle-office.sh` | Office 版の自動テスト（5件）を `dist/office-test.html` にまとめる（Office がなくても動く） |
| `office/taskpane.html?test` | Office 版の自動テスト（5件） |
| `tools/bundle.sh` | 全部を1つの HTML（`dist/sousa-sensei.html`）にまとめる。1ファイルで配りたいときに |

## 困ったとき

| 症状 | どうする |
|---|---|
| 共有の画面が真っ黒・選べない | 画面収録の許可（① の最初の1回だけ 2.）→ Chrome を開き直す |
| ミニ窓が開かない | 点滅している「📌 ミニ窓で表示」を押す（Chrome 116 以降が必要。Safari 不可） |
| 何秒待っても次へ進まない | 20秒たつと助け舟と「できた？」が出ます。ウインドウだけを共有しているなら「画面全体」で共有し直す。急ぐなら「次へ →」 |
| 光る場所がずれる・出ない | ウインドウを大きくする（文字が小さいと読めない）。ミニ窓の「認識した文字」で読めている文字を確かめる |
| AI がおかしい・遅い | モデルを `gemini-3.8-flash` にする。「🤖 AIに聞く」で聞き直す |
| 「回数制限に達しました」 | 少し待つ（無料枠の制限。そうさ先生側でも4秒に1回・1分に8回までにしています） |
| 文字認識が「準備中…」のまま | ネット接続を確認（初回は約2MBを読み込む） |
| 🌐 で「拡張機能が見つかりません」 | ② の「最初の1回だけ」をやり直す。特に「ファイルの URL へのアクセスを許可する」と、`index.html` の再読み込み |
| 拡張機能のアイコンを押してもパネルが出ない・古い画面のまま | `chrome://extensions` で「そうさ先生 Web 連携」の 🔄（再読み込み）を押し、Colab のタブも再読み込み |
| サイドパネルに「このページでは案内できません」 | Colab のタブを前に出してから「🤖 AIに聞く」。練習ページ（ファイル）なら「ファイルの URL へのアクセスを許可する」を ON |
