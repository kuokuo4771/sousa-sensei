# 操作ナビ (SousaNavi) 画面設計

## 1. デザイン方針

- 初心者が「今すること」を迷わず読めることを最優先にする
- Photoshopの作業領域を圧迫しない小さな案内ウインドウにする
- 装飾より状態、手順、確認操作を優先する
- macOS標準の見た目と操作方法に合わせる
- 操作中にボタン位置やウインドウサイズを変化させない
- 色だけに頼らず、アイコンと文章でも状態を伝える

## 2. 基本ウインドウ

- 標準サイズ: 360 × 520pt
- 最小サイズ: 320 × 420pt
- 初期位置: Photoshopウインドウと重ならない画面右側
- 常に最前面: 初期値オン
- タイトルバー: 最小化、サイズ変更、設定
- 角丸: macOS標準。独自パネルは最大8pt
- 背景: システム背景色
- アクセント: システムブルー
- 成功: システムグリーン
- 注意: システムオレンジ
- 停止・危険: システムレッド

ライトモードとダークモードの両方でmacOSのシステムカラーを使用する。

## 3. 共通レイアウト

```text
┌──────────────────────────────────┐
│ 操作ナビ                   [設定] │
├──────────────────────────────────┤
│ Photoshop  ● 監視中              │
│ [ 案内 | 自動実行 ]              │
├──────────────────────────────────┤
│ 手順 2 / 5                       │
│                                  │
│ トーンカーブを追加します         │
│                                  │
│ レイヤーパネル下部の             │
│ 「調整レイヤー」を選択してください│
│                                  │
│ 画面の変化を待っています...      │
├──────────────────────────────────┤
│ [戻る] [判断できない] [次へ]     │
│ [■ 停止]                         │
└──────────────────────────────────┘
```

レイアウト領域:

1. 対象・状態バー
2. モード切り替え
3. 手順表示
4. 解析または確認状態
5. 固定操作バー

下部操作バーの高さとボタン位置は全状態で固定する。

## 4. 初回起動画面

### 4.1 ようこそ

```text
┌──────────────────────────────────┐
│ 操作ナビ                         │
├──────────────────────────────────┤
│ Photoshopの画面を見ながら、      │
│ 色調補正を一手ずつ案内します。   │
│                                  │
│ 画像はMac内で解析されます。      │
│                                  │
│                    [設定を始める]│
└──────────────────────────────────┘
```

機能一覧や長い説明は表示しない。

### 4.2 画面収録許可

- 権限状態をアイコンと文章で表示
- 「許可する」でmacOSの許可導線を開始
- 許可後はアプリへ戻るだけで自動再確認
- 「再確認」を用意
- 管理者権限やターミナルを求める文章は表示しない

### 4.3 モデル取得

表示項目:

- モデル名
- ダウンロード容量
- Mac内で動作すること
- 保存先の空き容量
- 進行率、残り容量
- 一時停止、再開、キャンセル

ダウンロード失敗時は完了済みデータを保持し、再開できるようにする。

## 5. セッション開始画面

```text
┌──────────────────────────────────┐
│ 操作ナビ                   [設定] │
├──────────────────────────────────┤
│ 対象                             │
│ [ Photoshop - 写真.psd       ▾ ] │
│                                  │
│ モード                           │
│ [ 案内 | 自動実行 ]              │
│                                  │
│ やりたいこと                     │
│ ┌──────────────────────────────┐ │
│ │ この写真を自然な色に補正したい│ │
│ └──────────────────────────────┘ │
│                                  │
│                    [▶ 開始する] │
└──────────────────────────────────┘
```

- Photoshopウインドウはポップアップメニューで選択
- 入力欄にはMVPの依頼文を初期表示
- 対象がない場合は開始ボタンを無効化
- 自動実行へ切り替える際だけアクセシビリティ権限を確認

## 6. 案内中

### 6.1 解析中

- 小さな進行インジケータ
- 「画面を確認しています」
- 前回の手順は薄く残し、内容の飛びを防ぐ
- 戻る、判断できない、停止は使用可能
- 次へは解析完了まで無効

### 6.2 手順表示

- 見出しは一手だけを命令形で表示
- 補足は最大3行を基本とする
- 長い説明は展開ボタンで表示
- 操作対象名は太字
- 成功条件を短く表示

例:

```text
トーンカーブを追加します

レイヤーパネル下部の「調整レイヤー」を選び、
「トーンカーブ」をクリックしてください。

完了の目印:
トーンカーブのプロパティが表示されます。
```

### 6.3 変化検知

- 変化検知直後に「変更を確認しました」と表示
- 次の解析へ進むまで現在の手順を維持
- 誤検知を避けるため短時間の安定確認を入れる

### 6.4 完了

```text
┌──────────────────────────────────┐
│ ✓ 色調補正が完了しました         │
│                                  │
│ 明るさ、色かぶり、彩度を         │
│ 調整レイヤーで補正しました。     │
│                                  │
│ [履歴を見る]        [終了する]   │
└──────────────────────────────────┘
```

## 7. 判断できない

```text
┌──────────────────────────────────┐
│ 画面を確認できませんでした       │
├──────────────────────────────────┤
│ 現在はレイヤーパネルが閉じている │
│ 可能性があります。               │
│                                  │
│ [安全な手順を表示]               │
│ [画面をもう一度確認]             │
│ [前の手順へ戻る]                 │
└──────────────────────────────────┘
```

- 原因を断定しない
- 安全な推測と再解析を分ける
- 自動実行は提示しない

## 8. 自動実行確認

```text
┌──────────────────────────────────┐
│ 操作を実行しますか？             │
├──────────────────────────────────┤
│ 対象: 調整レイヤーボタン         │
│ 操作: 1回クリック                │
│ 結果: 調整項目の一覧を開く       │
│                                  │
│ マウスを動かすと停止します。     │
├──────────────────────────────────┤
│ [キャンセル]            [実行]   │
└──────────────────────────────────┘
```

- 1画面につき1操作だけを確認
- 実行ボタンは青、停止は赤
- 対象を再確認できない場合、実行ボタンを無効化
- 実行後は画面変化を確認してから次の操作を提案

## 9. 停止状態

- 停止理由を短く表示
- 追加操作は一切実行しない
- 「案内を再開」と「セッションを終了」を表示
- マウス移動による停止の場合、設定変更へのリンクを表示

## 10. 設定画面

macOS標準の設定ウインドウとして表示する。

### 一般

- 常に最前面: トグル
- 初期位置: ポップアップメニュー
- 状態通知: トグル

### 画面取得

- 取得範囲: ポップアップメニュー
- 変化検出間隔: ステッパー
- 画面収録権限: 状態表示と確認ボタン

### AI

- 画像評価: トグル
- 低メモリモード: トグル
- モデル: 状態、容量、更新、削除

### 自動実行

- 実験機能を有効化: トグル
- 操作前に確認: オン固定
- マウス移動で停止: トグル
- アクセシビリティ権限: 状態表示と確認ボタン

### 履歴

- 文章履歴: トグル
- スクリーンショット: トグル
- 保存期間: ポップアップメニュー
- 「すべて削除」: 確認ダイアログ付き

## 11. キーボードとアクセシビリティ

- Tabキーですべての操作要素へ移動可能
- Returnは主要操作、Escapeはキャンセルまたは停止
- 自動実行中の停止ショートカットを設定可能にする
- VoiceOver用ラベルをすべてのアイコンへ付与
- 文字サイズを上げてもボタンと本文が重ならない
- 長い日本語は省略せず、必要に応じて改行する
- 状態変化をVoiceOverへ通知する

## 12. UI受け入れ条件

- 320 × 420ptでも主要ボタンが隠れない
- ライト、ダーク両モードで文字が読める
- 解析中も停止操作が常に見える
- モードの違いを色だけに依存せず表示できる
- 自動実行の対象と操作内容を実行前に確認できる
- 長いPhotoshopウインドウ名がレイアウトを押し広げない
- 案内ウインドウ自体が解析画像へ混入しない
