# そうさ先生 (SousaSensei)

パソコンのソフト（PowerPoint・Excel・Google Colab など）の画面を見ながら、**次にやることを1つずつ、操作する場所を光らせて**日本語で教えるブラウザアプリです。
（2026-10-28 に「スライド先生」から改名。最終的には Blender・Illustrator なども教えられるようにするのが目標です）

- インストール不要・Python 不要。Chrome で HTML を開くだけで動きます
- 基本の案内（変化検知・文字認識・ハイライト）はすべてブラウザ内で処理し、画像を外部へ送りません
- AI は任意（無料）。Chrome 内蔵AI（端末内）か Gemini API 無料枠を選べます → [AI を使う](#ai-を使う任意無料)
- 案内は「ミニ窓」（常に最前面の小窓）に出るので、教わりたいソフトの横に置いて使えます

**使い方は [docs/USAGE.md](docs/USAGE.md)** にまとめています（本体・Web アプリ連携・Office アドインの3つ）。

## 使い方

1. **Google Chrome** で [`index.html`](index.html) を開く（ダブルクリックで OK。GitHub Pages で公開したら、その URL を開くだけ）
2. PowerPoint（日本語版）で新しいプレゼンテーションを開いておく
   - PowerPoint がない場合は、案内パネルの「📊 PowerPoint のレッスン」→「🧪 PowerPoint 風の練習用画面を開く」で試せます
3. 「🖥 画面を共有してはじめる」→ **画面全体**を選ぶ（おすすめ）。練習用画面だけを使うなら**タブ**でも可
   - Mac ではメニューやダイアログ（表のマス目、グラフの種類など）が別ウインドウなので、
     ソフトのウインドウだけを共有するとそれが写らず、AI や変化検知が反応できません
   - 画面全体でも、ミニ窓とこのページは塗りつぶしてから読むので、案内の文字を読み違えません
   - 案内のミニ窓（常に最前面）が同時に開きます。開かなかったときは、点滅する「📌 ミニ窓で表示」を押してください
   - 教わりたいソフトをクリックして前に出します
4. 案内の「🧭」欄にやりたいことを書いて「開始」、または「📊 PowerPoint のレッスン」から選ぶ。あとは操作するだけ。次の手順は**音声**でも読み上げます
   - 文字で確かめられる手順は自動で次へ進みます
   - それ以外は「できましたか？」と聞くので「できた ✓」を押します
   - 「⏩ 自動で次へ」を ON にすると、「できた？」のあと4秒で自動的に進みます（操作中は待ちます）

初回は macOS の **システム設定 → プライバシーとセキュリティ → 画面収録とシステムオーディオ録音** で Chrome を許可し、Chrome を再起動してください。

## Web アプリ（Google Colab など）とつなぐ

Web アプリは、Chrome 拡張機能「そうさ先生 Web 連携」（`extension/`）を使うと、もっと正確に案内できます。
**Colab を開いて拡張機能のアイコンを押すだけ**で、Chrome の右側（サイドパネル）に案内が出ます（本体も画面共有もいりません）。

- ボタン・メニュー・入力欄の**名前と位置をページから直接読む**（文字認識いらず。アイコンだけのボタンも名前が分かる）
- **ページの上に直接**ハイライトを出す
- 操作したら、ページが落ち着いたところで「変わった」と知らせる（勝手に動く表示は無視）
- AI には部品の一覧とタブのスクリーンショットを渡す（🧭 AIにおまかせ と組み合わせて使う）

### 入れ方（最初の1回だけ）

1. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」を ON
2. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダの中の `extension` フォルダを選ぶ
   （入れ直したときは 🔄 で再読み込み）
3. ツールバーの 🧩 →「そうさ先生 Web 連携」の 📌 でツールバーに出しておく

### 使い方（サイドパネル・おすすめ）

1. Google Colab のノートブックを開く
2. ツールバーのそうさ先生のアイコンを押す → 右側にサイドパネルが開く（初回は下の「AI の設定」で AI を選ぶ）
3. やりたいこと（例: セルを実行したい、GPU を使いたい）を書いて「開始」
4. Colab のページで赤く光った場所を操作すると、AI が確かめて次の一手を出します。迷ったら「できた？」に答える

本体の `index.html` の「🌐 Web アプリにつなぐ」からつなぐこともできます（ファイルの URL へのアクセスの許可が必要）。
詳しくは [docs/USAGE.md](docs/USAGE.md) の ②。

## Office アドイン（Excel・Word・PowerPoint）

Office の中の「作業ウィンドウ」に、案内そのものを表示します（ミニ窓もブラウザとの行き来もいりません）。

- 文書の状態を Office から**正確に**読む（Excel: 選択範囲・値・書式・罫線・表・グラフ／Word: 選択中の文章・書式・段落・表／PowerPoint: スライド・図形・文字）
- やりたいことに合う**テンプレ**があれば AI を使わずに案内する。なければ AI が最初に全体の手順を1回だけ考え、あとは AI を使わない
- 押すボタンは**リボンの道順**（ホーム › 罫線 › 格子）で表示して読み上げ、文書の中の場所（セル範囲・文章・図形）は**選択して見せる**
- 文書の状態に現れる言葉（近似曲線の「Linear」など）で「できたか」を確かめる。確かめられないときは「できた？」で聞く
- リボンのボタンそのものは光らせられません（Office の決まり）。光らせたいときは本体の画面共有モードを使います
- AI は Gemini API 無料枠のみ（Office の中では Chrome 内蔵AI が使えない）。APIキーは作業ウィンドウの「AI の設定」で入れる

### 入れ方（GitHub Pages などで https 公開したあと）

Office アドインは **https で公開した場所からしか読み込めません**。公開のしかたは [docs/USAGE.md](docs/USAGE.md) の ③。公開したら:

1. `tools/set-office-url.sh https://ユーザー名.github.io/リポジトリ名` → `dist/manifest.xml` ができる
2. Finder で ⌘⇧G を押し、次のフォルダを開いて `manifest.xml` をコピー（フォルダがなければ作る）
   - Excel: `~/Library/Containers/com.microsoft.Excel/Data/Documents/wef`
   - Word: `~/Library/Containers/com.microsoft.Word/Data/Documents/wef`
   - PowerPoint: `~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef`
3. Office を開き直し、「ホーム」→「アドイン」から「そうさ先生」を選ぶ

## AI を使う（任意・無料）

上部の「🤖 AI」から選びます。AI は次の3つに使います。

| 機能 | 内容 |
|---|---|
| **🧭 AIにおまかせ** | **どのソフトでも**。やりたいことを書くと、AI が共有中の画面を見て次の一手を1つずつ出し、場所を光らせる。画面が変わるたびに AI が「できたか」を確かめて次へ進む（判断できないときは「できた？」で聞く）。レッスンを前もって作る必要がない |
| 🤖 AIに聞く | 決まったレッスンの途中で、今の画面を見せて次の一手を聞く |
| 「できた？」にひとこと | 色・配置・テーマなど文字で判定できない手順で、「できているようです／まだのようです。次は…」と添える（「できた？」は残る） |

**場所の決め方（Set-of-Mark）**: 文字認識で見つけた画面上の文字すべてに番号札を付けた画像と一覧を AI に渡し、
「何番を操作するか」を選ばせます。AI に座標やボタン名を作らせないので外れにくく、光らせる位置は文字認識の正確な値をそのまま使います。
文字のないアイコンだけのボタン（ツールバーなど）も、画像から「同じ大きさで縦か横に並んだ形」を見つけて「［アイコン］」の番号札を付けます（`js/icons.js`）。
番号札のない場所（図形やスライドの中など）だけ、AI が推定した範囲を使います。
暗い画面のソフト（Photoshop・Premiere など）の文字も読めるよう、区画ごとに明暗を判定して白黒にしています。

| 方法 | 料金 | 画像の扱い | 準備 |
|---|---|---|---|
| **Chrome 内蔵AI**（Gemini Nano） | 無料 | **端末の外に出ない** | Chrome 148 以降（日本語は 149 以降）。初回に約3〜4GBのモデルを取り込む。空き容量 20GB・メモリなどの条件あり |
| **Gemini API 無料枠**（標準は `gemini-3.8-flash`。設定画面のメニューで選ぶ） | 無料（回数制限あり） | Google に送られ、**無料枠では製品改善に使われる** | [Google AI Studio](https://aistudio.google.com/apikey) で APIキーを作り、設定画面に貼る |

- Gemini 無料枠では、社外秘や個人情報が写る画面で使わないでください
- APIキーはこのブラウザの中（localStorage）にだけ保存されます
- 無料枠を使い切らないよう、AI の呼び出しは4秒に1回・1分に8回までに制限しています

## やることテンプレ（AI を使わない手順書）

`js/templates.js` の `TEMPLATE_LIBRARY` に、本体（画面共有）と Office 版で共通の形で書きます。
やりたいことにキーワードが入っていれば、AI を呼ばずにそのテンプレで案内します。

- 対応しているソフト: Excel・Word・PowerPoint・Google スプレッドシート・Illustrator・Photoshop・Blender（`js/templates.js` の `APPS`）。
  案内パネルの「使うソフト」で選ぶか、画面の文字やウインドウ名から自動で見分け、そのソフトのテンプレだけを使い、AI にもそのソフトの画面の作りを伝える
- **公式ヘルプから作る**: 公式ヘルプのページの文章を貼ると、AI が1回でテンプレにする（出典の URL つき）。
  本体は「⚙ 設定 → 📘 テンプレの管理」、Office 版は「📘 公式ヘルプからテンプレを作る」、
  拡張機能はサイドパネルの「📘 このページからテンプレを作る」（公式ヘルプのページで押すだけ。できたテンプレはコピーして本体や Office 版で読み込む）
- 増やし方: AI の計画でうまくいったら、完了したときの「📘 この手順をテンプレに保存」。
  「📘 テンプレの管理」（本体）・「📘 テンプレの書き出し・読み込み」（Office 版）で書き出した JSON を、`TEMPLATE_LIBRARY` に貼れば全員が使える
- `path`（押す順のボタン名）は、画面共有では1つずつ光らせ、Office 版では道順のチップで見せる。
  Photoshop・Blender などは `app` を変えて、メニューの道順（例: `["フィルター", "ぼかし", "ぼかし（ガウス）"]`）を書けば同じ仕組みで使える
- いま入っている3つ（Excel の近似直線・罫線、PowerPoint の表）は**見本**で、実物の Office で確かめていません（メニューに「（見本）」と出ます）

## レッスン

| レッスン | ステップ | 自動確認 | ハイライト |
|---|---|---|---|
| はじめてのスライド | 新規作成 → タイトル枠 → タイトル入力 → サブタイトル → 新しいスライド | 5 / 5 | 4 / 5 |
| 図形を使いこなす | 挿入タブ → 図形を描く → 塗りつぶし → 中央に配置 | 2 / 4 | 3 / 4 |
| 見やすいデザインテーマ | デザインタブ → テーマ適用 → 見比べ → 決定 | 1 / 4 | 1 / 4 |

自動確認できないステップは、画面の変化を検知して「できましたか？」と聞きます。

## 動作要件・制約

- Google Chrome 116 以降（ミニ窓に Document Picture-in-Picture を使用）。Safari ではミニ窓が使えません
- 初回のみ、文字認識の部品と日本語データ（約2MB）を jsDelivr から読み込みます
- PowerPoint の**明るい**テーマ向けです。暗い背景のテーマでは、灰色のプレースホルダー文字を読めないことがあります
- ブラウザからは PowerPoint の画面に直接描けないため、ハイライトはミニ窓とプレビューの中に表示します

## 開発

### ファイル構成（js/）

ふつうの `<script>` で順番に読み込みます（ダブルクリックで開いても動くように、ES モジュールは使っていません）。
後のファイルは前のファイルで作ったものを使うので、`index.html` の読み込み順を変えないでください。

| ファイル | 役割 |
|---|---|
| `ai.js` | AI 連携（Chrome 内蔵AI / Gemini API 無料枠、呼び出し回数の制限、答えの読み取り） |
| `lessons.js` | 決まったレッスンの定義（手順・完了条件・光らせる場所） |
| `templates.js` | やることテンプレ（AI を使わない手順書。本体と Office 版で共通。保存・書き出し・読み込み） |
| `core.js` | 設定値・状態（`state`）・画面の部品（`el`）・保存される設定・読み上げ |
| `steps.js` | 手順の表示と進め方（次へ・戻る・できた？・記録） |
| `capture.js` | 画面共有と、共有画面のフレーム取得（画面全体のときは自分の窓を塗りつぶす） |
| `detect.js` | 画面の変化検知（カーソルを無視し、操作が落ち着いてから判定） |
| `ocr.js` | 文字認識と、文字によるステップ完了の判定 |
| `icons.js` | アイコンだけのボタンを画像から見つける（番号札を付けて AI に選ばせるため） |
| `highlight.js` | 操作する場所のハイライト |
| `som.js` | 番号札（Set-of-Mark）を画面に描く・AI が選んだ札を文字で確かめる（拡張機能と共通） |
| `coach.js` | 番号札に使う部品の取り出しと 🧭 AIにおまかせ |
| `connector.js` | Web アプリ連携（拡張機能との取り次ぎ・つなぐ画面） |
| `ui.js` | AI 設定画面・やりたいこと入力欄・⚙ 設定・ミニ窓・テーマ |
| `main.js` | 起動（必ず最後） |
| `selftest.js` | 自動テスト（`index.html?test` のときだけ読み込む） |

CSS は `index.html` の中にあります。ミニ窓（Document PiP）へそのまま複製して使うためです。

### 自動テスト

`index.html?test` を Chrome で開くと、46 件のテストを実行して右下に結果を出します（約1分）。
画面共有と AI は偽物に差し替え、PowerPoint 風・Photoshop 風の画面を描いて確かめます。
文字認識だけは本物を使うので、初回はネット接続が必要です。テストのあとは AI の設定（APIキー）を元に戻します。

- ダブルクリックで開いた `index.html` には `?test` を付けにくいので、アドレスバーの末尾に `?test` を足して Enter
- 直したら必ず実行して、すべて ✅ になることを確かめる

### 1ファイル版を作る

```bash
tools/bundle.sh
```

`dist/sousa-sensei.html` に、すべてをまとめた1つの HTML ができます（`--test` を付けるとテストも入る）。
