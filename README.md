# スライド先生 (SlideSensei)

PowerPoint を **AI が実画面を見ながら日本語で一手ずつ教える** macOS 用ネイティブ MVP。

- 画面収録APIで PowerPoint ウインドウを 3〜5 秒ごとにキャプチャ
- Google Gemini（`gemini-2.0-flash`）に画像とレッスン文脈を送り「次の一手」を判定
- 常に最前面のフローティング窓（約 380×560pt）に指示を表示
- ユーザーが正しく操作すると AI が完了を検知して自動で次ステップへ

## セットアップ

### 1. Gemini API キーを取得
https://aistudio.google.com/apikey で無料キーを作成（`gemini-2.0-flash` は無料枠内で動作）。

### 2. 起動
Finder で `start.command` をダブルクリック。
初回は自動で仮想環境を作り、`requirements.txt` をインストールします。
初回起動画面で API キーを貼り付けて「保存して続行」。

キーは `~/.sousanavi/config.json` に保存されます（外部送信はキーそのものではなく、通常のGeminiリクエストのみ）。

### 3. macOS 画面収録の許可
初回キャプチャ時に macOS が「画面収録の許可」を求めます。
- システム設定 → プライバシーとセキュリティ → 画面収録 → **ターミナル** または **Python** を有効化
- 一度アプリを終了して再起動

### 4. PowerPoint を開いてレッスン開始
1. Microsoft PowerPoint を起動して新規プレゼンテーションを開く
2. スライド先生の窓でレッスンを選択（`はじめてのスライド` など）
3. PowerPoint をフォアグラウンドにする（スライド先生は最前面のまま）
4. AI が画面を認識し、次にすべき一手を提示

## 収録レッスン（MVP）

| ID | レッスン名 | 内容 |
|---|---|---|
| `first-slide` | はじめてのスライド | タイトル入力 → 本文 → 新しいスライド追加 |
| `insert-shape` | 図形を使いこなす | 挿入タブ → 図形 → 色変更 → 配置 |
| `design-theme` | 見やすいデザインテーマ | デザインタブ → テーマ選択 → 比較 → 確定 |

追加のレッスンは `main.py` の `LESSONS` 辞書に定義を追記するだけで増やせます。

## 動作要件

- macOS 12.3 以上（Apple Silicon 推奨）
- Python 3.10 以上
- インターネット接続（Gemini API 呼び出しに使用）
- Microsoft PowerPoint（日本語版で動作確認）

## プライバシー

- 送信されるのは PowerPoint ウインドウのスクリーンショット（長辺 1024px に縮小）+ レッスン文脈のテキストのみ
- APIキーはローカル (`~/.sousanavi/config.json`) 保存
- 画面変化がないときは AI 呼び出しをスキップ（コストと通信量を節約）
- 画像はローカルに保存されません

## トラブルシューティング

- **「PowerPointをフォアグラウンドにしてください」で止まる** → PowerPoint のウインドウをクリックしてアクティブにする
- **キャプチャが真っ黒** → 画面収録の許可を付与し、ターミナル/アプリを再起動
- **AI応答エラー** → API キーとネット接続を確認、`~/.sousanavi/config.json` を削除して再設定
