スライド先生へようこそ

PowerPoint の画面を見ながら、次にやることを1つずつ、
操作する場所を光らせて教えます。

  1. 1教わりたいソフト（PowerPoint・Excel・Blender など。なければ「練習用画面」）を開いておく
  2. 2「はじめる」を押し、画面全体を選ぶ（おすすめ）。 メニューやダイアログも見えるので、AI が反応しやすくなります。ソフトのウインドウだけを選ぶこともできます
  3. 3そのソフトをクリックして前に出し、あとは操作するだけ。 案内は最前面のミニ窓と音声で届きます。ミニ窓の「🧭」欄にやりたいことを書くと AI が案内します

Google Colab などの Web アプリなら、画面共有の代わりに拡張機能でつなぐと、 ボタンの名前と位置を正確に読み、ページの上に直接光らせて案内できます。

画像と文字認識はこのブラウザ内だけで処理します（AI を Gemini にした場合だけ、画面の画像を Google に送ります。 画面全体を共有すると、ほかのアプリや通知も写るので注意してください）。
ミニ窓とこのページは、画面全体を共有しても塗りつぶしてから読むので、案内の文字を AI が読み違えることはありません。
（文字認識の部品と日本語データ 約2MB を初回だけ jsDelivr から読み込みます）

    🌐 Web アプリにつなぐ
    
  
    Google Colab などの Web アプリは、Chrome 拡張機能「スライド先生 Web 連携」でつなぐと、
    ボタン（アイコンだけのボタンも）の名前と位置を正確に読み、ページの上に直接光らせて案内できます。画面共有はいりません。
    
  
    
    
    拡張機能が見つかりません。次の手順で入れてください（最初の1回だけ）。
    
    
      
      
    1. Chrome のアドレスバーに chrome://extensions と入力して開く
      2. 
      
    2. 右上の「デベロッパー モード」を ON にする
      3. 
      
    3. 「パッケージ化されていない拡張機能を読み込む」を押し、このアプリのフォルダの中の extension フォルダを選ぶ
      4. 
      
    4. 「スライド先生 Web 連携」の「詳細」を開き、「ファイルの URL へのアクセスを許可する」を ON にする
        （ダブルクリックで開いたこのページとつなぐために必要）
      5. 
      
    5. このページを再読み込みする
      6. 
    
    
  
    
  
    
    
    見つからないときは、Colab などを別のタブで開いてから「更新」を押してください。練習には practice-colab.html も使えます。
